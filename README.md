# Python To-Do List Application

A simple command-line To-Do List application developed using Python.  
This project helps users manage daily tasks directly from the terminal.

## Features
- ➕ Add tasks
- 📄 View tasks
- 🗑️ Remove tasks
- ✏️ Edit tasks
- 🚪 Exit application

## Technologies Used
- Python

## Concepts Used
- Lists
- Loops
- Conditional Statements
- User Input
- Functions and Basic Logic

## How to Run
1. Install Python
2. Open terminal or command prompt
3. Run the file using:

```bash
python todo.py
